# Bus Booking Website Design Patterns Analysis

## Key Design Patterns Extracted

### 1. Visual Hierarchy & Layout
**Hero Section with Booking Widget**
- Front-and-center booking card with search/fields
- Image overlay or full-bleed background
- Clear value proposition above the fold
- Responsive grid layout for booking form

**Popular Routes Cards**
- Quick-select destination cards with route info
- 3-4 cards per row on desktop
- Hover effects and subtle animations
- Clear pricing and route information

**3-Step Process**
- Numbered process indicators
- Simple icons for each step
- Clean card-based layout

### 2. Color Palette
**Azha Travel Signature Colors**
- **Primary:** #E74C3C (coral red - energetic and trustworthy)
- **Secondary:** #2C3E50 (dark blue - professional and stable)
- **Accent:** #F39C12 (warm orange - friendly and approachable)
- **Backgrounds:** #FFFFFF (white) and #F8F9FA (light gray)
- **Text:** #2C3E50 (dark blue for readability)

### 3. Typography
**Font Hierarchy**
- **Headers:** 'Poppins', 700 weight, 2.5rem - 4rem (responsive)
- **Body:** 'Open Sans', 400 weight, 1rem - 1.2rem
- **CTA Buttons:** Medium weight, 1.1rem with text-transform: uppercase

### 4. UI Components
**Booking Form**
- Glass-morphism effect for form container
- Rounded corners (16px) with soft shadows
- Error states and validation feedback
- Mobile-first responsive design

**Route Cards**
- Border-radius: 12px
- Soft shadows: 0 4px 15px rgba(0,0,0,0.1)
- Hover state with lift effect
- Gradient overlays for images

**Navigation**
- Sticky top navigation
- Dropdown menus with smooth transitions
- Mobile hamburger menu

### 5. Interactive Elements
**Buttons**
- Primary: rounded pill buttons with subtle hover
- Secondary: outline buttons with brand color
- CTA: full-width buttons on mobile

**Cards & Panels**
- Soft shadows for depth
- Hover animations
- Image overlays with gradient fades

### 6 of 8 patterns:** testimonials-with-stars

**Testimonials Section**
- Quote icons for visual interest
- Star rating display (5-point scale)
- Author name and location
- Quoted text with proper attribution

### 7 of 8 patterns:** responsive-app-download

**App Download Section**
- Clean, minimalist download buttons
- App store badges (Apple, Google Play)
- Simple value proposition
- QR code option for mobile

### 8 of 8 patterns:** trust-badges-social-proof

**Trust & Social Proof**
- User count badges ("10,000+ students served")
- University logos or trust indicators
- Social media following counts
- Press mentions or awards (if applicable)

## Visual Hierarchy for Azha Travel

### Mobile-First Approach
1. **Above the Fold**
   - Hero with bus image background
   - Booking form visible immediately
   - Clear value proposition

2. **Popular Routes**
   - Grid of 2-3 route cards
   - Include pickup point, time, price
   - Quick selection buttons

3. **How It Works**
   - 3 simple steps with icons
   - Clear timeline visual

4. **About & Services**
   - Text on image sections
   - Feature cards with icons
   - Timeline of service history

5. **Testimonials**
   - Star ratings for each testimonial
   - Carousel on mobile, grid on desktop
   - Student quotes with university affiliation

6. **Contact & Booking**
   - Contact info with icons
   - Contact form with WhatsApp integration
   - Address and map location
